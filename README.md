# 🧾 JOBID Attendance System

A workforce attendance application using JOBID-based login system, designed for field workers, couriers, and operational teams.

## 🚀 Features

### 👷 Worker (Mobile App)
- Login using JOBID (no email required)
- Check-in (Masuk)
- Check-out (Pulang)
- Auto daily attendance validation
- Location tracking (Google Maps link)
- Work recap
- Earnings calculation (optional)

---

### 🧑‍💼 Admin (Web Dashboard)
- Monitor attendance per worker
- Per city attendance tracking
- Daily attendance summary
- Worker management
- Export data

---

## 🧩 Tech Stack
- Frontend: FlutterFlow
- Backend: Supabase
- Database: PostgreSQL
- Storage: Supabase Storage

---

## ⚙️ System Logic
- 1 worker = 1 JOBID
- 1 check-in & 1 check-out per day
- Attendance based on worker_id
- Map location stored as URL (Google Maps)

---

## 🏙️ Coverage
- Multi-city support
